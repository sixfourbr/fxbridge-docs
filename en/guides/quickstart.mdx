---

In this guide you confirm that your integration reaches FXBridge environments by calling the
`GET /v1/ping` endpoint, which requires no authentication.

<Steps>
  <Step title="Choose the environment">
    Start with **Sandbox** (`https://sandbox.fxbridge.com.br`). See the details in
    [Environments](/en/guides/environments).
  </Step>
  <Step title="Send the request">
    <CodeGroup>

    ```bash cURL
    curl --request GET \
      --url https://sandbox.fxbridge.com.br/v1/ping
    ```

    ```javascript JavaScript
    const response = await fetch('https://sandbox.fxbridge.com.br/v1/ping');
    const body = await response.json();
    console.log(body.message, body.timestamp);
    ```

    ```python Python
    import requests

    response = requests.get("https://sandbox.fxbridge.com.br/v1/ping", timeout=10)
    response.raise_for_status()
    print(response.json())
    ```

    </CodeGroup>
  </Step>
  <Step title="Check the response">
    A `200 OK` response means the service is available:

    ```json
    {
      "message": "pong",
      "timestamp": "2026-11-19T08:57:35Z"
    }
    ```

    The `timestamp` field holds the server time in UTC (ISO 8601).
  </Step>
</Steps>
