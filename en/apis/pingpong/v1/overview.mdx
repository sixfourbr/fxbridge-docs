title: "Overview"
description: "Ping-Pong API v1: connectivity check against FXBridge environments."
---

The Ping-Pong API answers `GET /v1/ping` with the message `pong` and the server time in UTC.
Use it to confirm that your integration reaches FXBridge environments.

| Environment | Base URL |
|---|---|
| Sandbox | `https://sandbox.fxbridge.com.br` |
| Production | `https://api.fxbridge.com.br` |
